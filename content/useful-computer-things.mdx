Arch Linux - Never been easier to use Linux. This lets me do all sort of weird and wonderful automations. 

Tmux - I run all of my coding agents through Tmux sessions inside of Kitty terminal emulator

Neovim - My main text editor, I was using it with Obsidian for a while but now I have fully switched over. It's very useful to have everything in the terminal. (Although I suspect this could change very soon! It is too constrained)

Tridactyl - A Firefox extention so good it made me switch to Firefox. I was using Vimium on Chrome for a while but I found it too buggy. Tridactyl has great link hints, visual selection, marks. Which is great if you are trying to use keyboard shortcuts more. 

I vibecoded a browswer extention to sleep every tab that I haven't looked at in 15 minutes to save memory.(I hoard tabs)
