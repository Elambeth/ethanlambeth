I type on a Corne v4 split keyboard. These are the layers I live in: base for typing, lower for numbers and navigation, raise for symbols, plus a mouse layer. Switch between them below (or click a layer key on the board).

::keyboard-layout::

## Shortcuts

The layout feeds a Hyprland + tmux setup. The main modifier is `⌘` (Super — the right-hand `LGUI` key); **Ctrl** is the left-pinky column (the `Tab` / `⇧` / `Ctrl` stack).

**At a glance:** new terminal `⌘+U` · app launcher `⌘+K` · close window `⌘+C` · tmux prefix `Ctrl+T`.

### Hyprland (mod `⌘`)

| Key | Action |
|---|---|
| `⌘+U` | Terminal (kitty) |
| `⌘+K` | App launcher (rofi) |
| `⌘+L` | Clipboard history |
| `⌘+C` | Close window |
| `⌘+V` | Toggle floating |
| `⌘+F` | Fullscreen |
| `⌘+N` | Center window |
| `⌘+1…0` | Switch workspace |
| `⌘+←/→/↑/↓` | Move focus |
| `⌘+⇧+←/→/↑/↓` | Move window |
| `⌘+R` | Toggle color theme |
| `⌘+W` | Random wallpaper |

### tmux (prefix `Ctrl+T`)

Press `Ctrl+T`, then:

| Key | Action |
|---|---|
| `h` / `v` | Split right / down |
| `c` | New window |
| `Space` | Copy mode (vi keys) |
| `g` | Git commit (popup) |
| `n` | Daily note (popup) |
| `Ctrl+c` | New window running `claude` |
